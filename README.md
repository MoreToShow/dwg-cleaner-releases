# More To Show - DWG Cleaner releases

Release files and the update feed for **More To Show - DWG Cleaner**, an internal tool of
More To Show. The app only works with a More To Show account.

- **[User manual (PDF)](DWG-Cleaner-Manual.pdf)**: installing, signing in, converting a drawing, the options.
- **[Download the latest version](https://github.com/MoreToShow/dwg-cleaner-releases/releases/latest)**: the signed disk image.
- `appcast.xml`: the update feed the app checks (Sparkle). Once installed, the app updates itself.

The source code is private.
